## Install

```bash
pip install "evpanda[zstd]"
```

<Note>
  The Python SDK is in **preview** and has no HTTP adapters yet. Until it reaches PyPI, install it from source:

  ```bash
  pip install "git+https://github.com/evpanda-labs/evpanda-py"
  ```

  Everything on this page uses the capture methods directly, which is a stable API — the adapters, when they land, will be a convenience on top of it.
</Note>

## Start the client

```python evpanda_client.py
from evpanda import OCPIClient, OCPIConfig

# api_key omitted → read from the EVPANDA_API_KEY environment variable.
panda = OCPIClient.start(
    OCPIConfig(
        endpoint="https://ingest.evpanda.io",
        ocpi_allowed_headers=["x-correlation-id"],  # extends the allowlist
    )
)
```

An OCPI client needs an OCPI API key, from a **roaming network**. A charger network's key will be rejected.

## The capture calls

Two methods, one per direction. The method name sets the direction — there is no field to pass.

```python
from evpanda import HttpExchange, OCPIMessageInput, RoamingIdentity

panda.capture_inbound_message(   # partner → you
    OCPIMessageInput(
        identity=RoamingIdentity(
            platform_id="acme",
            platform_name="Acme Mobility",
        ),
        data=HttpExchange(
            method="POST",
            url="/ocpi/2.2/cdrs",
            status_code=201,
            request_headers={"content-type": "application/json"},
            response_headers={"content-type": "application/json"},
            request_body=b'{"id":"cdr-1"}',
            response_body=b'{"status_code":1000}',
        ),
    )
)
```

`capture_outbound_message` is the same call for traffic you initiated.

| Field | Required | Notes |
| --- | --- | --- |
| `method`, `url` | Yes | |
| `status_code` | No | Omit when there was no response |
| `request_headers`, `response_headers` | No | Default to empty dicts; filtered by the allowlist |
| `request_body`, `response_body` | No | `bytes`, capped at `max_capture_bytes` |

Both calls are non-blocking and never raise back at you.

## Inbound: partners calling you

A middleware sits in the one place that sees the whole exchange. This example is FastAPI and Starlette; the shape is the same for Django or Flask.

```python middleware.py
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import Response

from evpanda import HttpExchange, OCPIMessageInput, RoamingIdentity

from evpanda_client import panda


class EVPandaMiddleware(BaseHTTPMiddleware):
    """Capture inbound OCPI exchanges. Mount it after authentication, so
    the partner has already been resolved by the time it runs."""

    async def dispatch(self, request: Request, call_next):
        identity = resolve_partner(request)
        if identity is None:
            return await call_next(request)  # not captured, served normally

        request_body = await request.body()
        response = await call_next(request)

        # Drain the streaming response so the body can be captured, then
        # hand the client an equivalent buffered response.
        chunks = [chunk async for chunk in response.body_iterator]
        response_body = b"".join(chunks)

        panda.capture_inbound_message(
            OCPIMessageInput(
                identity=identity,
                data=HttpExchange(
                    method=request.method,
                    url=str(request.url),
                    status_code=response.status_code,
                    request_headers=dict(request.headers),
                    response_headers=dict(response.headers),
                    request_body=request_body,
                    response_body=response_body,
                ),
            )
        )

        return Response(
            content=response_body,
            status_code=response.status_code,
            headers=dict(response.headers),
            media_type=response.media_type,
        )


def resolve_partner(request: Request) -> RoamingIdentity | None:
    """Your existing partner lookup — the same one that decided whether to
    serve this request at all."""
    partner = lookup_partner(request.headers.get("authorization"))
    if partner is None:
        return None
    return RoamingIdentity(platform_id=partner.id, platform_name=partner.name)
```

Mount it after your auth middleware:

```python app.py
app = FastAPI()
app.add_middleware(EVPandaMiddleware)   # runs inside…
app.add_middleware(AuthMiddleware)      # …this one
```

<Warning>
  Starlette applies middleware outside-in, so the **last** one added runs first. Adding auth after capture is what puts auth on the outside, where it must be — get this backwards and no request will ever have an identity to capture with.
</Warning>

<Note>
  Buffering the response body is what lets you capture it, and it means streaming endpoints are materialized in memory. If you serve large OCPI list responses as streams, capture those routes selectively rather than site-wide.
</Note>

## Outbound: your calls to partners

Wrap the call site. You have already looked the partner up to get their Token B, so the identity is in hand.

```python client.py
import httpx

from evpanda import HttpExchange, OCPIMessageInput, RoamingIdentity

from evpanda_client import panda


async def call_partner(
    partner, method: str, path: str, json: dict | None = None
) -> httpx.Response:
    async with httpx.AsyncClient(base_url=partner.base_url) as client:
        response = await client.request(
            method,
            path,
            json=json,
            headers={"authorization": f"Token {partner.token_b}"},
        )

    panda.capture_outbound_message(
        OCPIMessageInput(
            identity=RoamingIdentity(
                platform_id=partner.id,
                platform_name=partner.name,
            ),
            data=HttpExchange(
                method=response.request.method,
                url=str(response.request.url),
                status_code=response.status_code,
                request_headers=dict(response.request.headers),
                response_headers=dict(response.headers),
                request_body=response.request.content,
                response_body=response.content,
            ),
        )
    )

    return response
```

Capture after the call returns, not before — you need the status and the response body. A call that raises at the transport layer has no exchange to record, so let the exception propagate and capture nothing.

<Tip>
  For `httpx`, an event hook on `response` works too, as long as you call `await response.aread()` first. A wrapper function is easier to reason about and gives you one obvious place to attach identity.
</Tip>

## Multi-tenant platforms

Add the tenant pair to the identity. It is optional but all-or-nothing.

```python
RoamingIdentity(
    platform_id="acme",
    platform_name="Acme Mobility",
    tenant_id="cpo-42",
    tenant_name="CPO 42",
)
```

## Shut down cleanly

```python
@app.on_event("shutdown")
def close_evpanda() -> None:
    panda.close()  # drains within drain_timeout, 10s by default
```

`close()` blocks while it drains and never raises. Captures made after it are safe no-ops.
